Синхронизация защищает действующие маршруты от неполных и устаревших источников и корректно обрабатывает медленные записи в UniFi.

Изменения:

- Проверка идентификатора снимка, состояния и возраста источника из заголовков `iplist-go`. Состояния `degraded` и `stale` блокируют запись.
- Защита от потери покрытия: `max_removal_ratio` по умолчанию равен `0.35`. Эквивалентное объединение или разбиение CIDR не считается удалением; для доменов учитываются родительские домены.
- Проверки `min_entries`, `max_entries` и `allow_empty` продолжают действовать вместе с новыми ограничениями.
- После ошибки записи маршрут повторно читается из UniFi. Если контроллер уже применил нужный список, операция считается успешной. Устаревший локальный hash больше не вызывает повторную запись совпадающего маршрута.
- Таймаут API по умолчанию увеличен до 120 секунд; исключены одновременные прогоны синхронизации.
- `/status` показывает снимок, время источника, потерю покрытия и причины блокировки. Исправлено отображение состояния синхронизации при старте.
- CA-сертификаты включены в образ. Публикуются образы для `linux/amd64` и `linux/arm64`; добавлены тесты защитных проверок и неоднозначного результата записи.

Обновление с v0.2:

1. Сохраните конфигурацию и runtime-volume с резервными копиями правил. Обновите образ до `ghcr.io/dexogen/iplist-go-unifi:v0.3`.
2. Для источников `iplist-go` сначала обновите приложение до v0.3 и включите `safety.require_fresh: true`, `safety.max_source_age: "48h"`. Примеры конфигурации уже включают эту проверку. По умолчанию `require_fresh` выключен для совместимости с источниками без метаданных; присутствующие метаданные проверяются всегда.
3. Учтите новый предел `safety.max_removal_ratio: 0.35`. Для намеренного массового удаления проверьте изменения через dry-run и задайте подходящий предел в `sources[].safety`; значение `1` разрешает любую долю удаления, сохраняя остальные проверки.
4. Перед включением записи выполните `iplist-go-unifi -config ./config.yml -once -dry-run` и проверьте `/status`. Для медленных контроллеров с крупными списками увеличьте `unifi.timeout`, например до `"300s"`.

```bash
docker pull ghcr.io/dexogen/iplist-go-unifi:v0.3
```
